# Cursor 提示词：堆叠通知

请在现有 React + TypeScript 项目中实现一个可复用的 `ToastStack`。

要求：

1. 通知队列由外部受控，新通知插入数组开头。
2. 折叠时让后续通知逐层后退并缩小，展开时显示完整间距。
3. 关闭任意通知后，其余通知连续补位。
4. 支持默认、成功、提醒和失败状态，状态必须包含文字。
5. 支持可控进度条、操作按钮和带可读名称的关闭按钮。
6. 使用 `aria-live` 表达新增状态，按钮可通过键盘操作。
7. 支持 `prefers-reduced-motion`，不使用随机位置。
8. 提供组件、样式、接入示例和纯函数测试。
