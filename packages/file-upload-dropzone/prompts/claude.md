# Claude 提示词：拆解并重构智能文件上传区

请分析当前项目的文件输入流程，并重构为一个可复用的 `FileUploadDropzone`。中文展示名为“智能文件上传区”。目标是让用户在每一步都清楚知道能否放入、是否已接收、处理进度和最终结果。

实现要求：

1. 使用浏览器原生 File API、Drag and Drop API、React 和 TypeScript。
2. 保留原生 `<input type="file">` 作为点击、触屏和键盘入口。
3. 拆分默认、拖入目标、处理中、完成和错误状态。
4. 对文件类型、大小和数量进行可测试的前端校验，并提醒服务端仍需再次校验。
5. 把真实上传和进度获取交给业务层，不把接口或存储地址写死在组件内。
6. 处理多层元素触发 `dragenter` 与 `dragleave` 时的状态闪烁。
7. 提供 `aria-live`、进度语义、焦点样式和拖拽替代操作。
8. 不复制第三方仓库源码、品牌视觉或未授权素材。
