# Claude 提示词：圆形主题切换

请为 React + TypeScript 项目编写一个独立的 Circular Theme Reveal 组件。

实现约束：

- 接收 light / dark 两种主题内容。
- 从主题按钮中心计算动画原点。
- 使用勾股计算到容器最远角的覆盖半径。
- 通过 Web Animations API 驱动 `clip-path` 圆形揭示。
- 覆盖层不能响应点击，也不能被辅助技术重复读取。
- 动画进行时阻止二次触发。
- 支持减少动画偏好、键盘操作和移动端。
- 保持实现精简，不引入动画依赖。

同时给出测试：验证中心点半径、角点半径、关键帧字符串和主题切换状态。
