# Cursor 提示词：圆形主题切换

请在现有 React + TypeScript 项目中实现一个可复用的圆形主题切换组件。

要求：

1. 新主题从触发按钮中心以 `clip-path: circle()` 扩张。
2. 半径根据点击点到容器最远角的距离动态计算，不写死尺寸。
3. 动画时长可配置，默认 560ms。
4. 动画期间禁用重复触发，结束后再提交最终主题状态。
5. 触发按钮支持键盘和明确的 `aria-label`。
6. 系统开启 `prefers-reduced-motion: reduce` 时直接切换。
7. 不依赖第三方动画库，不复制任何第三方组件源码。
8. 输出组件、必要 CSS、参数说明和最小使用示例。
