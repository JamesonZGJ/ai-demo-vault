# 圆形主题切换

《每天拆一个 AI 产品》第 014 期 Build Block。点击切换按钮后，新主题会从按钮中心以圆形扩张，直到覆盖整个容器。

## 适合场景

- AI 工作台的深浅主题切换
- SaaS 控制台
- 开发者工具
- 内容与阅读产品

## 设计要点

1. 动画从用户刚刚点击的位置开始，操作和结果更容易对应。
2. 半径取点击点到容器最远角的距离，保证新主题完全覆盖。
3. 动画期间只让覆盖层响应视觉变化，避免重复内容接收点击。
4. 系统开启“减少动画”时直接切换主题。

## 已包含

- React + TypeScript 自研源码
- 圆形半径与关键帧计算函数
- 键盘可操作的主题按钮
- 减少动画适配
- 中文接入指南与参数说明
- Cursor / Claude 实现提示词
