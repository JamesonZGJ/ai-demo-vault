# Claude 提示词：拖拽排序列表

为一个 React + TypeScript 产品实现 `SortableList`，用于调整 AI 工作流步骤和任务优先级。

实现约束：

- 自研排序逻辑，不依赖拖拽组件库。
- 采用受控数据：`items` + `onChange`。
- 使用 Pointer Events 和指针捕获。
- 拖动时显示浮动副本，原项目保留为占位。
- 根据指针下方项目计算临时顺序，松手后再提交。
- 提供可点击的上移/下移按钮，满足不拖动也能完成排序。
- 支持手柄上的 `ArrowUp` / `ArrowDown`。
- 使用 `ol` / `li`、清晰的按钮名称和 `aria-live` 状态播报。
- 第一项不能继续上移，最后一项不能继续下移。
- 支持取消操作并恢复拖动前顺序。
- 不改变输入数组，不使用随机标识。
- 兼容 360px 移动端。
