# Cursor 提示词：拖拽排序列表

请在现有 React + TypeScript 项目中实现一个可复用的拖拽排序列表。

要求：

1. 数据由外部 `items` 控制，每项必须有稳定 `id`。
2. 使用 Pointer Events，同时支持鼠标、触控笔和触屏。
3. 拖动开始后保留占位，浮动卡片跟随指针。
4. 指针经过其他项目时，先更新临时顺序，让落点在松手前可见。
5. 松手后通过 `onChange` 返回新的完整数组。
6. 浮动卡片必须设置 `pointer-events: none`。
7. 手柄使用 `setPointerCapture` 保持拖动连续性。
8. 提供上移和下移按钮，不能只依赖拖动。
9. 手柄聚焦时支持上下方向键排序。
10. 使用语义化有序列表和 `aria-live` 播报位置。
11. 不使用随机数，不修改原数组，不使用数组下标作为 key。
12. 为纯排序函数补充边界测试。

请输出组件、样式、示例数据和测试，并说明移动端与可访问性处理。
