# 玻璃拟态卡片

《每天拆一个 AI 产品》第001期。

`Glass Surface` 是一个自研、可复用的 Glass Card 能力模块。它把玻璃拟态从一次性的视觉效果整理成一组可以接入 AI 产品的明确参数：模糊、透明度、边框、高光、阴影和鼠标交互。

## 适合使用的地方

- AI Dashboard 的结果卡片
- 生成式 AI 的预览面板
- Hero 和产品介绍页面
- 媒体、图片和 Prompt 预览容器

## 为什么 AI 产品常用它

在 Cursor、Vercel、Perplexity、Raycast、Linear 和 OpenAI 等产品的面板、浮层或结果区域，可以观察到不同程度的分层表面、半透明边界或柔和阴影。它们并不都使用同一种玻璃拟态，但共享几个适合 AI 工作流的设计目标：

1. AI 输出通常需要同时展示输入、过程和结果，表面层级可以把信息分成容易扫读的区域。
2. 半透明背景保留上下文，让用户知道自己仍在同一个工作空间里。
3. 模糊、边框和阴影提供了轻量的视觉边界，不会像厚重的纯色面板一样打断阅读。
4. 鼠标高光和微小位移给出明确反馈，让等待、预览和选择状态更有触感。

这些是对公开产品体验的设计观察，不代表复制任何产品的源码、素材或品牌样式。

## 设计拆解

舒服的玻璃卡片并不是单靠透明度完成的。背景需要有足够的颜色层次，卡片用轻微的边框和内高光建立边界，再用模糊把前后景分开。指针高光和小幅倾斜只负责反馈，不应抢过内容本身。
