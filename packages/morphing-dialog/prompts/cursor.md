# Cursor 提示词：卡片变形弹窗

请在现有 React + TypeScript 项目中实现一个可复用的 Morphing Dialog 组件。

要求：

1. 点击卡片时记录触发元素的 `getBoundingClientRect()`。
2. 弹窗从原卡片矩形过渡到居中的目标矩形，关闭时沿原路径返回。
3. 卡片和弹窗复用标题、说明和视觉内容，保持空间连续性。
4. 支持关闭按钮、Escape、点击遮罩关闭、焦点循环与焦点恢复。
5. 弹窗打开时锁定页面滚动，窗口变化时重新计算目标尺寸。
6. 支持 `prefers-reduced-motion: reduce`，减少动画时直接切换。
7. 不依赖第三方动画库，不复制任何第三方组件源码。
8. 输出组件、必要 CSS、参数说明、最小使用示例和测试。
