# Claude 提示词：卡片变形弹窗

请为 React + TypeScript 项目编写一个独立的 Morphing Dialog 组件。

实现约束：

- 用触发卡片矩形作为动画起点，用视口内居中矩形作为终点。
- 打开和关闭必须沿同一条位置、尺寸与圆角路径运动。
- 卡片和弹窗共用语义内容，避免复制不同标题造成视觉断裂。
- 使用 Portal 渲染遮罩与弹窗，正确设置 `role="dialog"` 和 `aria-modal`。
- 支持焦点循环、焦点恢复、Escape、点击外部关闭和页面滚动锁定。
- 视口变化时更新目标矩形，移动端保留安全边距。
- 系统开启减少动画时直接完成状态切换。
- 不使用第三方动画依赖，不复制参考组件源码。

同时给出矩形计算单元测试，以及打开、关闭、键盘和 360px 响应式浏览器测试。
