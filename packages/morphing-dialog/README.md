# 卡片变形弹窗

《每天拆一个 AI 产品》第 015 期 Build Block。点击卡片后，相同的视觉内容从原卡片位置连续扩展成详情弹窗；关闭时沿原路径返回。

## 适合场景

- AI 模型与 Agent 详情
- 图片生成结果预览
- 模板、工作流和项目卡片
- 内容详情与媒体预览

## 设计要点

1. 打开前记录触发卡片的位置和尺寸。
2. 弹窗先从原卡片矩形出现，再过渡到居中目标矩形。
3. 卡片与弹窗复用标题、视觉和语义，避免视线重新寻找内容。
4. 关闭时恢复焦点，并支持 Esc、点击外部和焦点循环。
5. 开启“减少动画”时直接完成状态切换。

## 已包含

- 卡片到弹窗的矩形计算与状态控制
- 焦点循环、焦点恢复和页面滚动锁定
- Esc、点击外部关闭和减少动画适配
