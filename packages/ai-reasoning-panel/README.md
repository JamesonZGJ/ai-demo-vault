# AI 思考过程面板

《每天拆一个 AI 产品》第 016 期 Build Block。它把等待、生成、完成和手动查看组织成一个可复用的折叠面板，让用户知道系统正在处理什么，又不会让过程信息长期挤占最终答案。

## 适合场景

- AI 聊天与搜索
- Agent 任务执行
- 文档分析与内容生成
- 多步骤后台处理

## 设计要点

1. 等待或生成开始时自动展开。
2. 完成后延迟收起，把空间交还给最终结果。
3. 用户手动操作后尊重用户选择，不继续强制自动切换。
4. 状态文本与颜色同时变化，不能只依赖颜色表达。
5. 只展示可公开的处理摘要，不展示或伪造模型私密思维链。

## 已包含

- React + TypeScript 自研源码
- 五种状态与自动展开/收起逻辑
- 手动操作优先级和完成延迟
- 中文接入指南与参数说明
- Cursor / Claude 实现提示词
