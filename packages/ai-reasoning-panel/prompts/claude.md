# Claude 提示词：AI 思考过程面板

请为 React + TypeScript 项目编写一个独立的 AI Reasoning Panel 组件。

实现约束：

- 业务层传入 idle、waiting、streaming、complete 或 error 状态。
- 新任务进入等待或生成时自动展开；完成或失败后按配置延迟收起。
- 用户手动操作后，组件必须尊重用户选择，避免自动状态抢夺控制权。
- 使用语义化按钮和区域关联，状态变化必须具有可读文字。
- 支持移动端和减少动画偏好。
- 摘要只能是公开、可解释的处理阶段，严禁展示或伪造模型私密思维链。
- 不依赖第三方动画库，不复制参考组件源码。

同时提供状态映射单元测试，以及自动展开、手动优先和 360px 响应式浏览器测试。
