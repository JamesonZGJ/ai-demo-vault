# Cursor 提示词：骨架屏加载

请在现有 React + TypeScript 项目中实现一个可复用的 `SkeletonLoader`。

要求：

1. 由外部 `loading` 控制，不在组件内部伪造网络请求。
2. 骨架结构包含可选头像、标题、正文和操作区。
3. 正文行数支持参数配置，并限制合理范围。
4. 真实内容出现前后保持稳定尺寸，减少布局跳动。
5. 加载容器使用 `aria-busy`，提供屏幕阅读器状态文本。
6. 流光使用 CSS 实现，并支持 `prefers-reduced-motion`。
7. 不使用随机宽度，保证服务端与客户端输出一致。
8. 提供组件、样式、接入示例和纯函数测试。
