# Cursor Prompt：AI Agent 任务收件箱

请在现有 React + TypeScript 项目中实现一个 AI Agent 任务收件箱。

要求：

1. 任务状态包含 needs_attention、in_review、in_progress、completed。
2. 默认排序为需要处理、等待审查、运行中、已完成。
3. 需要处理的任务必须展示具体原因，不能只放红点。
4. 运行中任务显示由业务层传入的真实进度。
5. 支持全部、需要处理、运行中、等待审查四个筛选。
6. 点击任务只触发回调，由业务层负责恢复原执行上下文。
7. 状态文字、筛选状态和进度可被辅助技术读取。
8. 支持键盘和 360px 移动端，不增加外部 UI 依赖。
9. 不伪造 Agent 执行、任务成功或后台进度。

输出组件、CSS、参数说明、使用示例和最小测试。
