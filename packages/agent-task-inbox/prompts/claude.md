# Claude Prompt：AI Agent 任务收件箱

分析现有代码结构后，为 React + TypeScript 项目新增一个 AI Agent 任务收件箱。

组件职责：把多个 Agent 的关键状态集中展示，让用户先看到需要处理和等待审查的任务，并能返回原执行现场继续操作。

约束：

- 状态为 needs_attention、in_review、in_progress、completed。
- 排序规则稳定，且不能修改传入数组。
- 需要处理项展示原因；运行中项只展示真实进度。
- 筛选、任务选择和状态更新具有明确可访问语义。
- 组件不连接模型、不轮询接口、不假装任务执行成功。
- 保持依赖最少，支持桌面端和 360px 移动端。
- 接入文档说明服务端数据、状态更新和恢复执行上下文的职责。
