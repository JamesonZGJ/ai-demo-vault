# AI Agent 任务收件箱

`Agent Task Inbox` 是一个给 AI 工作台、AI IDE 和多 Agent 产品使用的任务聚合组件。它把需要用户处理、等待审查、运行中和已完成任务放进同一个视图，让用户先看见真正需要介入的节点。

## 适合场景

- 多 Agent 并行执行
- 长任务和后台任务
- AI 编程与代码审查
- 内容生成和发布流程
- 需要人工确认的自动化工作流

## 设计重点

- “需要你处理”任务排在最前，并显示具体原因。
- 等待审查、运行中和已完成使用独立文字，不能只依赖颜色。
- 运行中任务只展示真实进度，不用消息持续刷屏。
- 点开任务应回到原来的执行上下文，继续确认、审查或调整方向。
- 组件只展示任务数据，不负责启动或执行 Agent。
