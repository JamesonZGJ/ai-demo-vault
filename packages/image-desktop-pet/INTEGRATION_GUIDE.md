# 图片桌宠接入指南

1. 准备 PNG、JPG 或 WebP；透明 PNG 的边缘最干净。
2. 父容器设置 `position: relative`、明确高度和 `overflow: hidden`。
3. 传入稳定图片地址；本地上传使用 `URL.createObjectURL`，替换或卸载时释放 URL。
4. Pointer Down 时记录指针与角色起点，移动时计算差值，不累加误差。
5. 使用父容器尺寸减去角色尺寸计算最大坐标，禁止拖出边界。
6. 保留 Pointer Capture，避免快速拖动时丢失角色。
7. 给角色提供可读名称与方向键操作，不把拖拽作为唯一入口。
8. 尊重 `prefers-reduced-motion`，关闭非必要待机动画。

系统桌面接入：

- Electron：透明、无边框、置顶 `BrowserWindow`，再按角色区域决定点击穿透。
- Tauri：透明、无装饰、置顶窗口；多显示器坐标必须由系统窗口层处理。
- 网页组件只负责角色交互，不声称拥有系统窗口权限。

验收：拖动连续、边界准确、方向键可用、容器缩放后位置仍有效、360px 无横向溢出。
