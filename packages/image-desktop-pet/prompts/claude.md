# Claude 提示词：图片桌宠

为 React + TypeScript 产品实现 `ImageDesktopPet`，把一张本地图片变成可拖动、会轻微呼吸的互动角色。

- 支持常见图片地址和浏览器 Blob URL。
- 使用 Pointer Capture 保证快速拖动连续。
- 根据父容器和角色尺寸限制坐标。
- 容器缩放后重新限制当前位置。
- 提供方向键操作、可读名称和减少动画模式。
- 图片背景处理属于素材准备，不声称组件可以可靠移除任意复杂背景。
- 系统桌面常驻能力由 Electron 或 Tauri 窗口层实现。
- 兼容 360px 移动端。

交付组件源码、样式、参数说明、接入示例和测试。
