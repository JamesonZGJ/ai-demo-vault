# 智能聊天输入框接入指南

1. 用 `value` 和 `onChange` 接入真实表单状态。
2. `onSubmit` 只接收去除首尾空格后的文本，业务层负责请求。
3. Enter 发送前必须检查 `isComposing`，避免中文输入法确认候选时误发送。
4. Shift + Enter 保留为换行。
5. 生成中把主按钮切换为停止，并通过 `onStop` 中止业务请求。
6. 附件上传、校验和持久化由业务层处理；组件只展示已确认附件。
7. 错误信息放在输入框附近并用可访问状态区域播报。

验收：长文本增高、中文输入法不误发、附件可移除、停止状态清楚、360px 无溢出。
