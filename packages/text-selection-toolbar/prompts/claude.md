# Claude 提示词：文本选区工具栏

为 React + TypeScript 编辑器实现 `TextSelectionToolbar`。

- 监听非空文本选区，并验证选区完全位于编辑器内部。
- 根据 `Range.getBoundingClientRect()` 计算悬浮位置。
- 处理顶部空间不足、左右边缘和跨行选区。
- 点击工具栏时不要让编辑器先失焦。
- 操作列表和回调均可配置。
- 滚动、缩放后重新定位。
- 使用 `role="toolbar"` 和清晰的按钮文字。
- AI 请求、加载、取消、失败和写回由业务层负责。
- 兼容 360px 移动端。

交付组件、样式、参数说明、接入示例和测试。
