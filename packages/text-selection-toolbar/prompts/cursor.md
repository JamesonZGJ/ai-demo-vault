# Cursor 提示词：文本选区工具栏

请在现有 React + TypeScript 项目中实现可复用的 `TextSelectionToolbar`。

要求：

1. 只在有效的非空文本选区内显示。
2. 起点与终点都必须位于指定编辑器内。
3. 使用 Selection API 和 Range 矩形定位，不写死坐标。
4. 优先放在选区上方，上方空间不足时放到下方。
5. 水平方向限制在容器边界内。
6. 工具栏按下时保留原选区，回调能够取得所选文字。
7. 滚动、缩放和内容变化后重新定位。
8. 操作列表可配置，并提供可访问的 toolbar 语义。
9. AI 请求由业务层处理，组件不伪造模型结果。
10. 交付源码、样式、参数、接入指南和纯函数测试。
