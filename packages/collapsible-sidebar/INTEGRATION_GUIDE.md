# 可折叠侧边栏接入指南

1. 业务层维护 `activeId`、`collapsed` 和 `mobileOpen`。
2. 每个导航项使用稳定 `id`，不要用数组下标。
3. 收起状态必须给图标按钮保留可访问名称和悬停提示。
4. 切换按钮使用 `aria-expanded`，并通过 `aria-controls` 指向导航区域。
5. 移动端使用遮罩和抽屉；点击导航、遮罩或 Escape 后关闭。
6. 当前页面使用 `aria-current="page"`。
7. 侧栏宽度变化不能挤出页面横向滚动。

验收：桌面可展开/收起、图标可识别、移动端可打开/关闭、Escape 有效、360px 无溢出。
