# 流式聊天回复

英文内部名：`Streaming Chat`

面向 AI 对话和生成任务的回复组件，把请求等待、文字持续流入、自动滚动和完成状态组织成连续反馈。

## 已实现

- 等待、生成、完成和失败状态
- 回复文本按已到达字符逐步显示
- 新内容出现时自动滚动到末尾
- 生成光标和等待动画
- 屏幕阅读器可读取状态和回复变化
- 响应式布局与减少动画偏好

## 使用

```tsx
<StreamingChat
  prompt="为什么 AI 回复要流式显示？"
  response={response}
  status="streaming"
  visibleCharacters={visibleCharacters}
/>
```

## 来源与边界

交互规律来自对常见 AI 对话产品的观察，源码与视觉由本项目独立实现，不包含第三方品牌、素材或代码。
