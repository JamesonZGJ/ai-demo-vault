# Cursor Prompt：AI 操作授权确认卡

请在现有 React + TypeScript 项目中实现一个受控的 AI 操作授权确认卡。

要求：

1. 展示即将执行的动作、影响对象和风险说明。
2. 状态包含 pending、approved、rejected、executing、complete、error。
3. 只有 pending 状态显示“允许一次”和“拒绝”。
4. 拒绝后立即结束，不进入执行状态。
5. 组件不直接调用接口，允许和拒绝通过回调交给业务层。
6. 每个状态都要有独立文字，不能只依赖颜色。
7. 状态变化通过 aria-live 读出，按钮支持键盘操作和清楚焦点样式。
8. 响应式支持 360px 宽度，并尊重项目现有视觉系统。
9. 不伪造成功结果，不把前端点击当成真实权限校验。

输出组件、样式、使用示例和最小测试。
