# Claude Prompt：AI 操作授权确认卡

分析现有代码结构后，为 React + TypeScript 项目新增一个 AI 操作授权确认卡。

组件职责：在删除、发送、发布、部署或付费等敏感动作前，把动作、对象和风险说清楚，收集一次性允许或拒绝，并展示真实执行状态。

约束：

- 使用受控状态，不在组件内部执行真实业务。
- 状态为 pending、approved、rejected、executing、complete、error。
- pending 以外不再显示决策按钮。
- 拒绝必须终止流程；允许只针对当前请求。
- 状态文字可被辅助技术读取，按钮具备键盘和焦点支持。
- 业务接入文档必须说明服务端二次鉴权、幂等和审计记录。
- 保持依赖最少，支持移动端和减少认知负担。
