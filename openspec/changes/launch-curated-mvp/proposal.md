# Proposal: Launch curated MVP

## Why

目标用户需要的不是又一个链接导航站，而是一套能判断“产品为什么成立、如何实现、还能改成什么”的可信案例库。第一阶段最重要的验证是：原创拆解是否能带来公开访问、来源流量和真实收藏，而不是提前建设支付与会员系统。

## What changes

- 新建可运行的 AI Demo Vault Web 应用。
- 提供首页、案例库、详情页、搜索筛选、账号和收藏。
- 建立带来源、真实性、授权和评分理由的案例数据库。
- 首批发布 12 个官方可核验 AI 案例；ColorSnap 作为自有原型草稿，解决公开名称和素材授权后再发布。
- 建立 SEO、响应式、可访问性和自动验证。
- 固定创业改造的四项结构化字段，并支持合规图片、GIF、视频及失败状态。

## Change map

**产品形态**
- From: 当前只有项目设想和分散的 Demo 线索，没有可运行网站。
- To: 一个免费的中文 AI 产品案例库，包含首页、目录、详情、登录和收藏。
- Reason: 先验证可信拆解是否产生公开访问、来源流量和真实收藏。
- Impact: 新增 Web 应用和数据库；不影响工作区内其他项目。

**内容可信度**
- From: “已验证方向”、评分、截图和技术信息没有统一证据规则。
- To: 每条公开事实对应来源，案例区分实现成熟度与开源/商业/采用证据，素材必须获准公开。
- Reason: 可信度是产品区别于普通链接导航的核心。
- Impact: 内容录入成本上升，但未核验内容无法上线。

**商业化阶段**
- From: 设想同时包含单品、会员、Pro、支付和下载。
- To: MVP 只提供免费浏览、账号和收藏。
- Reason: 在用户信任和内容需求尚未验证前，支付系统不能证明商业模式成立。
- Impact: 首版没有收费入口；后续另提 Blueprint 商业化 change。

**ColorSnap #001**
- From: 计划直接作为首个 AI App Blueprint 发布。
- To: 先保存为未商业化、当前无 AI 的私有草稿，完成更名和素材授权后再决定公开。
- Reason: 现有原型包含模拟功能、未完整授权图片和同类商标风险。
- Impact: 不阻塞 12 个官方案例上线，也不误导用户。

## In scope

| 能力 | 首版交付 |
|---|---|
| 首页 | 今日精选、最新收录、创业灵感编辑榜；有真实收藏后显示“收藏最多” |
| 案例库 | 搜索、分类、工具、难度、发布方地区、排序、分页 |
| 详情页 | 截图/演示、在线体验、产品、痛点、用户、功能、AI 实现、技术、盈利、真实性、二次创新、来源 |
| 编辑判断 | 卡片商业潜力 1–5 分、规则版本和理由 |
| 账号 | 邮箱注册、登录、确认和退出 |
| 收藏 | 收藏、取消收藏、真实计数、个人收藏页 |
| 内容运营 | 人工策展、SQL 迁移、发布状态和素材授权检查 |
| SEO | 元数据、canonical、sitemap、robots |
| 最小统计 | 公开页面匿名聚合访问、访客和来源；私有页面不统计 |

完整商业目标继续记录在 `ROADMAP.md`，当前 change 只是第一个可验收阶段，不代表完整项目完成。

## Out of scope

- 支付宝、微信、Stripe。
- Blueprint 付费包、下载、会员权限和 Pro 咨询。
- 自动抓取、定时同步、AI 自动生成拆解。
- 管理后台、用户投稿、评论、评分和社区。
- 英文站点和双语路由。
- 用模拟数据填充收藏、热度或商业验证。
- 创新性、开发难度、市场竞争、复刻价值和综合创业排名等完整评分系统。

## Success criteria

1. 10 个优先分类均有可追溯案例，首批 12 个且总数不超过 30；至少各有 1 个中国与海外官方来源。
2. 游客可完成浏览、搜索、筛选和详情阅读。
3. 登录用户的收藏刷新后保留，且不同用户严格隔离。
4. 草稿、未授权素材和缺来源案例无法公开访问。
5. 所有卡片收藏数来自数据库；没有任何真实收藏时隐藏“收藏最多”，有收藏后按真实数量显示，且不称为热度。
6. `pnpm verify` 全部通过，生产构建成功。
7. 生产环境能看到公开页面匿名访问与来源，分析事件不包含邮箱、用户 ID、令牌或私有页面路径。

## Decisions requiring confirmation

- 首版为中文界面，英语版后置。
- 首版只验证免费数据库，不做任何收费入口。
- ColorSnap 只能以“未商业化原型”呈现，正式公开前处理名称和素材授权。
- 首版只保留商业潜力编辑判断；完整五维评分按原路线留到后期。
