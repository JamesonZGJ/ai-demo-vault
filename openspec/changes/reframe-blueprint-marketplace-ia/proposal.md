# Proposal: Reframe as a Blueprint marketplace

## Why

当前实现的首页、导航、路由、详情和账号中心都以免费 Demo 为最终产品，只能完成浏览与收藏。用户已经确认：项目的核心产品应是购买后获得完整复刻资料包的 Blueprint，Demo 只是免费发现与信任入口。

如果只在 Demo 详情页增加一个购买按钮，会混淆第三方案例与本站可售资产，也无法处理固定版本、精确价格、客户许可、订单、支付确认、会员权益和私有交付。本 change 先重建产品主次和信息架构，并为后续一个真实 Blueprint 成交闭环建立不可绕过的边界。

## Current evidence

| 能力 | 当前事实 |
|---|---|
| 公开页面 | 只有首页、Demo 目录/详情、隐私、账号和收藏 |
| 主导航 | 案例库、收藏和登录；没有 Blueprint、定价或资料库 |
| 数据库 | 案例、证据、媒体、来源、收藏；商业对象为 0 |
| 商品详情 | 不存在；Demo 详情只有体验、仓库、收藏和免费拆解 |
| 支付与交付 | 订单、支付回调、权益、私有下载、退款、对账均为 0 |
| 商业规范 | `COMMERCE_SPEC.md` 只有未来契约，不代表已实现 |

完整审计和目标页面树见 `MARKETPLACE_IA.md`。

## Material changes

| From | To | Reason | Impact |
|---|---|---|---|
| “全球 AI 产品案例库”是产品中心 | “AI Product Blueprint Marketplace”是产品中心，Demo 为免费入口 | 用户购买的是可复刻结果，不是案例链接 | 首页、导航、SEO、文案和阶段指标都要调整 |
| Demo 同时承担内容与潜在商品 | Demo、Blueprint、Entitlement 三类对象独立 | 第三方案例不等于本站有权出售源码 | 新增明确关系与原创/授权声明，禁止隐式售卖 |
| 只有 `/demos` 与收藏账号页 | 目标 IA 预留 Blueprint、定价、结账、订单、资料库、会员、咨询和法律页面族；本 change 只实现本地/预发布 Blueprint 与定价页面 | 先完成购买前决策结构，付款和购买后交付由独立 change 实现 | 当前只改变商品路由、SEO 与导航预览，不创建交易账号路由 |
| Demo 详情以返回案例库收口 | 只在有合法可售 Blueprint 时导向商品详情 | 让免费内容形成可验证转化，同时避免假按钮 | Demo 查询与详情增加显式商品关系和状态 |
| 商业化等待免费案例达到 100 项 | Blueprint #001 成交闭环与 Demo 内容增长并行 | 100 个案例不能证明有人愿意购买资料包 | 路线图与资源优先级改变 |
| 先规划“全部 Blueprint”会员 | 先证明一个固定版本单品；会员和 Pro 分别后置 | 避免订阅一个月无限下载，保护单品价值 | 权益、更新、到期和咨询规则需要独立验收 |
| “Marketplace”含义不明确 | 首阶段限定本站自营精选商店 | 多卖家会立即引入主体、分账、税务和争议系统 | 第一笔交易不实现卖家入驻与平台分成 |

## In scope

- 固定 Blueprint 为商品、Demo 为免费发现、未来 Entitlement 为交付权的领域边界；本 change 不创建 Entitlement。
- 在本地/预发布实现 Blueprint 目录、商品详情、Demo 转化入口和定价说明；交易账号页只保留目标文档，不创建运行时路由。
- 首页、主导航、页脚、站点地图和页面文案改为 Blueprint 优先。
- Blueprint 商品页固定展示八类交付物、版本、构建验证、权利、许可、更新和支持；公开购买状态展示已批准的退款与精确价格，授权预览允许明确写“价格/政策未决定”。
- 为商品、Demo 关系、固定版本、逐文件 manifest、文件权利、验证批次、Offer Version、Policy Version 和 Price 建立商品基础；只有合格可售版本可成为公开候选，激活 Offer 与 Price 才允许进入购买状态。
- 在目标文档中保留结账、订单、资料库、会员、咨询和下载边界；运行时代码不创建这些页面、API、订单、权益或占位流程。
- 把 Blueprint #001 的真实购买、授权、下载、退款和对账提前为公共商城上线闸门。
- 本 change 的首页、导航和商品页调整只在本地/预发布验收；生产公共 Blueprint 主导航与“可成交商城”声明保持关闭，直到 `launch-blueprint-001-sales` 通过。

## Out of scope

- 在本 change 中开通生产商户、发起真实扣款、退款或发布数字商品。
- 在 Blueprint #001 尚未通过八类交付物和权利门槛前制作假商品或占位成交。
- 第三方卖家入驻、KYC、合同、分账、提现、税务代扣、平台佣金或争议仲裁。
- 购物车、优惠券、联盟分销、动态定价和多币种自动换算。
- 直接上线 Builder Pass 周期扣款或 Pro 咨询服务。
- 创建结账、订单、支付回调、权益、资料库、会员、咨询或私有下载的运行时页面、API 和数据对象。
- 删除或关闭现有免费 Demo、收藏、证据和内容资产。

## Success criteria

1. 本地/预发布首页和主导航以 Blueprint 商品为第一入口，免费 Demo 明确为第二入口；生产公共入口保持关闭。
2. 本地/预发布 `/blueprints` 和 `/blueprints/[slug]` 只展示通过可售门槛的真实商品；空库显示真实状态，不生成假价格。
3. Blueprint 详情组件完整回答成品、八类交付物、逐文件验证、复刻要求、版本、权利、许可和支持；公开购买状态显示退款与精确价格，授权预览如实显示未决定项。
4. Demo 与 Blueprint 使用显式关系；没有商品时不显示购买按钮，第三方灵感商品显示原创复刻声明。
5. 结账、订单、资料库、会员、咨询和下载在依赖 change 完成前没有生产导航、路由、API、假订单或模拟权益。
6. 商品基础模型覆盖固定版本、逐文件 manifest、文件级权利、不可变验证、Offer/Policy Version 和精确 Price；交易对象留给后续 change。
7. 当前免费 Demo 功能、SEO、真实性证据和收藏继续通过现有测试。
8. 公共商城发布前必须有一个自营 Blueprint 在生产跑通购买、授权、下载、退款和对账；未通过时失败即停。

## Decisions requiring confirmation

- 确认首阶段为本站自营精选 Blueprint 商店，不做第三方卖家入驻。
- 确认本 change 只完成定位、信息架构与商品基础，不擅自开通生产支付。
- 后续在接支付前，用户另行决定销售主体、首个支付商、币种、精确价格、退款、税费和客户许可。
- Builder Pass 的领取额度、更新期限和到期后访问规则，以及 Pro 的咨询时长与交付方式，分别进入后续提案。
