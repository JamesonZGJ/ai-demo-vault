# 《每天拆一个 AI 产品》第019—025期设计稿

## 目标

连续制作七期 AI 原生交互内容，并为每期同步一个可复用的网站 Build Block。栏目继续服务产品设计师、独立开发者和前端工程师，重点解释真实 AI 产品中的状态、上下文、审查和长任务交互。

## 一周主题

主题：AI 工作台如何让复杂任务保持可理解、可控制、可继续。

|---|---|---|---|---|

## 选题顺序

第019期用一眼能看懂的引用展开建立本周开场；第020期提升到完整工作区；第021—024期依次覆盖工具、代码、记忆和附件；第025期用执行时间线收束整周，把前六期的状态设计组合成一个长任务场景。

## 视频统一结构

每期保持六幕、六句中文口播，时长控制在 40—45 秒：

1. 0—4秒：展示交互冲突或用户最容易困惑的瞬间。
2. 4—11秒：说明该能力在真实 AI 产品中的作用。
3. 11—19秒：拆解信息层级。
4. 19—28秒：展示关键状态变化。
5. 28—37秒：展示用户操作后的连续反馈。
6. 37—45秒：展示最终效果，并以平台内问题结束。

口播、字幕、画面关键词和场景时长必须来自同一份六句文本。旁白生成后，以真实音频边界重新计算 Remotion 场景长度。

## 视频内容边界

- 视频只讲产品设计、交互逻辑、用户体验和前端实现思路。
- 视频内不出现 Codex、Claude Code、Cursor、GitHub、网站、下载、源码地址、URL 或二维码。
- 来源产品和官方链接只记录在内部来源说明，不作为视频宣传对象。
- 不使用第三方品牌 Logo、完整产品录像或受保护插画。
- 所有展示界面均为自研重构，不暗示由参考产品官方提供。
- 结尾仅使用“评论区告诉我还想拆哪个 AI 交互”等平台内行动。

## 网站 Build Block

每期新增一个独立 Package，统一包含：

- 在线本地静态 Demo
- 自研 React + TypeScript 源码
- Cursor Prompt
- Claude Prompt
- 中文 README
- 参数说明
- 中文接入指南
- License
- manifest

网站预览只演示本地确定性状态，不调用真实模型、外部工具、代码仓库或文件服务。内容继续免费开放，不增加支付、会员、下载成功或虚假热度。

## 组件行为

### 第019期：Source Citation Preview

- 引用标记必须与来源项一一对应。
- 打开引用后就地显示标题、域名、原文片段和命中高亮。
- 键盘可以打开和关闭预览，关闭后焦点返回引用标记。
- 缺少来源时显示明确的不可核查状态。

### 第020期：Artifact Split Preview

- 左侧保留对话上下文，右侧展示独立成果。
- 生成、更新、完成和失败状态必须明确。
- 版本切换不会覆盖旧版本。
- 窄屏改为对话与成果标签切换。

### 第021期：Tool Call Activity Card

- 展示工具名称、目的、当前状态、耗时和结果摘要。
- 执行中只显示真实已完成步骤。
- 失败状态包含错误摘要和重试入口。
- 默认折叠技术细节，用户可主动展开。

### 第022期：AI Diff Review

- 文件列表显示改动数量与审查状态。
- 增加、删除和上下文行使用文字与颜色双重区分。
- 支持接受或拒绝当前文件，并自动进入下一项。
- 完成后展示真实审查进度，不模拟提交或合并成功。

### 第023期：Memory Update Control

- 记忆更新提示明确写出保存的具体内容。
- 用户可以查看、修改或忘记单条记忆。
- 临时会话状态明确说明不会使用或新增记忆。
- 删除操作只修改本地演示状态。

### 第024期：Multimodal Attachment Queue

- 附件拥有排队、上传、解析、完成和失败状态。
- 支持键盘排序、移除与失败重试。
- 进度必须单调递增，失败后保持文件信息。
- 不读取或上传用户真实文件。

### 第025期：Agent Execution Timeline

- 时间线展示计划、执行、等待用户、恢复和完成状态。
- 当前步骤必须唯一，完成步骤不可回到运行中。
- 等待用户时停止进度变化，并解释需要什么输入。
- 用户继续后从原步骤恢复，不重新创建任务。

## 视频视觉系统

- 1080×1920，30fps，40—45秒。
- 延续深蓝黑背景、薄网格、薄边框、薄荷绿主强调色。
- 每幕只保留一个标题、一个解释和一个主要交互舞台。
- 字幕保持底部安全区，最多三行。
- 3:4 与 4:3 封面沿用第018期信息层级，只更换标题、短问题和核心组件图。
- 动画只服务状态变化和视线引导，不增加装饰性复杂动画。

## 验收标准

- 七期口播与字幕逐字一致。
- 每期成片为 1080×1920、30fps、40—45秒。
- 两种封面尺寸分别为 1080×1440 和 1440×1080。
- 所有关键状态均有文字标签，不能只依赖颜色。
- 网站组件支持键盘使用和窄屏布局。
- 单元测试、ESLint、TypeScript 和生产构建全部通过。
- 视觉抽帧不存在裁切、遮挡、字幕溢出和信息过小。
- 网站源码提交前排除视频、旁白、缓存、密钥和本地环境文件。
