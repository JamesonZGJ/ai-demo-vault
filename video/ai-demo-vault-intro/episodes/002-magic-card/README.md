# 《每天拆一个 AI 产品》第 002 期

## 玻璃光斑卡片

本期观察一个跟随指针移动的卡片交互，把它拆成光斑、边框、倾斜和归位几个动作，再用自制示意完成一次重新实现。

- 内部名称：`Magic Card`
- 中文标题：玻璃光斑卡片
- 画幅：1080 × 1920
- 帧率：30fps
- 时长：42 秒

## 交付文件

- `SCRIPT.md`：中文口播与屏幕文案
- `STORYBOARD.md`：分镜
- `narration.txt`：旁白输入
- `captions.srt`：字幕
- `SOURCE_ANALYSIS.md`：交互分析与版权边界
- `SOCIAL_COPY.md`：平台内发布文案
- `COVER_COPY.md`：封面文字

画面使用自制演示，只讨论通用交互规律，不展示第三方页面、Logo、外部入口或工具名称。
