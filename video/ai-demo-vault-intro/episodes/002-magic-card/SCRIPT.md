# 第 002 期脚本：玻璃光斑卡片

## 口播稿

今天拆一个 AI 产品常见的交互：玻璃光斑卡片。

参考的是 Magic UI 的 Magic Card，GitHub 页面当前显示约 21.6k Stars，官方文档可以直接预览。

它舒服的原因很简单：光斑跟着指针移动，边框亮起，离开后回到中心。

我把它拆成指针坐标、径向渐变、边框强度、轻微倾斜和减少动效五个参数。

然后用 Codex 重新写了一遍。左边是参考交互，右边是自研版本。

它已经作为 Build Block #002 加入 AI Demo Vault。想看下一期，关注《每天拆一个 AI 产品》。
