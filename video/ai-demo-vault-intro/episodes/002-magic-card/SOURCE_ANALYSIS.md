# 玻璃光斑卡片：交互分析与原创重构边界

## 交互拆解

| 动作 | 视觉变化 | 设计作用 |
|---|---|---|
| 指针移动 | 光斑跟随坐标变化 | 让界面回应操作 |
| 指针靠近边缘 | 边框亮度提升 | 让卡片边界更清楚 |
| 指针离开 | 光斑回到中心 | 让状态回到平衡 |
| 轻微倾斜 | 卡片角度小幅变化 | 增加空间感，不改变布局 |
| 减少动效 | 关闭倾斜和快速移动 | 保持可读和可用 |

## 原创边界

本期只提炼公开交互中常见的反馈规律。卡片、代码、参数和对比画面均由本栏目独立制作，不使用第三方视频、Logo、源码、插画或品牌素材。

## QA

- [ ] 移动时光斑位置连续
- [ ] 离开后能回到中心
- [ ] 触摸设备仍然可读
- [ ] 减少动效时不出现快速倾斜
- [ ] 旁白、字幕、封面用词一致
