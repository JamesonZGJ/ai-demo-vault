# 《每天拆一个 AI 产品》第 003 期

## 流式聊天回复

本期拆解 AI 聊天里最常见的流式回复效果，把它拆成输入、请求、流式文本、自动滚动和完成状态五个部分，再用自制界面完成一次复刻。

- 内部名称：`Streaming Chat`
- 中文标题：流式聊天回复
- 画幅：1080 × 1920
- 帧率：30fps
- 时长：42 秒

## 交付文件

- `SCRIPT.md`：中文口播与屏幕文案
- `STORYBOARD.md`：分镜
- `narration.txt`：旁白输入
- `captions.srt`：字幕
- `SOURCE_ANALYSIS.md`：交互分析与版权边界
- `SOCIAL_COPY.md`：平台内发布文案
- `COVER_COPY.md`：封面文字

画面使用自制聊天示意，只讨论通用交互规律，不展示第三方页面、Logo、外部入口或工具名称。
