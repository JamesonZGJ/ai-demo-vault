# 玻璃拟态卡片：设计分析与原创重构边界

## 为什么 AI 产品常用这类卡片

| 设计规律 | 用户感受 | 实现重点 |
|---|---|---|
| 半透明表面 | 内容与背景有关系，但仍然独立 | 控制透明度和前后对比 |
| 背景模糊 | 后层内容被压低，前层信息更突出 | 限制模糊范围，保护可读性 |
| 细边框 | 卡片边界轻，不切断画面 | 使用低对比度细线 |
| 阴影与层差 | 卡片像浮在页面上 | 保持阴影范围小、透明度低 |
| 顶部高光 | 在复杂背景中提供视线锚点 | 用渐变表达方向 |
| Hover 微响应 | 用户知道卡片可操作 | 轻微位移、亮度或高光变化 |

## 设计判断

1. 信息层级先于装饰，文字必须先读清楚。
2. 模糊范围有限，避免背景抢走注意力。
3. 浅色和深色背景都要保持对比度。
4. 动效只做反馈，不制造额外负担。
5. 移动端保留层次，减少复杂偏转。

## 原创边界

本期只提炼公开产品中常见的视觉规律，卡片、参数和代码排版均为独立制作。画面不使用第三方 Logo、录屏、源码、插画或品牌素材，也不暗示原作品由本栏目制作。

## QA

- [ ] 文字与背景对比度足够
- [ ] 没有模糊能力时仍然可读
- [ ] Hover 不改变布局尺寸
- [ ] 移动端不出现横向滚动
- [ ] 旁白、字幕、封面用词一致
