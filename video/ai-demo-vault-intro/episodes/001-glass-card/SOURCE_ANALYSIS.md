# Glass Card 设计分析与原创重构边界

## 为什么 AI 产品常用 Glass Card

| 设计规律 | 用户感受 | 实现重点 |
|---|---|---|
| 半透明表面 | 内容与背景有关系，但仍然独立 | `background: rgba(...)`，控制透明度 |
| 背景模糊 | 后层内容被压低，前层信息更突出 | `backdrop-filter: blur(...)`，准备无滤镜降级方案 |
| 细边框 | 卡片边界轻，不会切断画面 | 低对比度 1px border |
| 阴影与层差 | 让卡片像浮在页面上 | 小范围、低透明度 shadow |
| 顶部高光 | 在复杂背景中提供视线锚点 | 鼠标位置驱动的 radial glow |
| Hover 微响应 | 用户知道卡片是可操作的 | 轻微位移、亮度或高光变化 |

## 为什么舒服

1. 信息层级先于装饰：文字和 CTA 必须清楚。
2. 模糊范围有限：过度模糊会损害可读性。
3. 对比度稳定：在浅色和深色背景上都能阅读。
4. 动效克制：鼠标响应只做反馈，不抢走注意力。
5. 响应式优先：移动端关闭复杂偏转，保留层次和可读性。

## 参考与许可证

Cursor、Vercel、Perplexity、Raycast、Linear、OpenAI 等产品仅作为“常见设计规律”的观察对象。视频不使用其 Logo、录屏、源码或页面截图；组件由本项目独立重新实现，具体来源和许可证在网站商品页单独记录。

## QA 检查

- [ ] 卡片文字与背景对比度足够
- [ ] `backdrop-filter` 不可用时仍可读
- [ ] Hover 不改变布局尺寸
- [ ] 移动端不出现横向滚动
- [ ] 来源说明和 License 字段完整
- [ ] 没有把未完成的源码或 Prompt 标记为 Ready
