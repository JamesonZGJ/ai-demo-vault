## 交付物

- `SCRIPT.md`：中文口播稿与屏幕文案
- `STORYBOARD.md`：42 秒竖屏分镜
- `narration.txt`：HyperFrames TTS 输入文本
- `captions.srt`：剪辑和发布用字幕
- `SOCIAL_COPY.md`：小红书、抖音、X 文案
