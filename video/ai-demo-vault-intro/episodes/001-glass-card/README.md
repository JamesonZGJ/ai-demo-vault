# 《每天拆一个 AI 产品》第 001 期

## 玻璃拟态卡片

本期只做一件事：把玻璃拟态卡片的视觉层次和交互反馈讲清楚，再用自制示意完成一次重新实现。

## 交付物

- `SCRIPT.md`：中文口播与屏幕文案
- `STORYBOARD.md`：42 秒竖屏分镜
- `narration.txt`：旁白输入文本
- `captions.srt`：字幕
- `SOCIAL_COPY.md`：平台内发布文案
- `COVER_COPY.md`：封面文字
- `SOURCE_ANALYSIS.md`：设计分析与原创重构边界

## 视频信息

- 内部名称：`Glass Card`
- 中文展示名：玻璃拟态卡片
- 画幅：1080 × 1920
- 帧率：30fps
- 时长：42 秒
- 语气：像独立开发者和产品设计师分享判断

## 素材边界

画面使用自制示意卡片和原创代码排版。参考效果只用于分析通用规律，不出现第三方标识、完整录屏或外部入口。视频不承载工具宣传、站外导流、下载或购买信息。
