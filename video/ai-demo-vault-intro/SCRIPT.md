# AI Demo Vault 产品介绍口播稿

## 口播方向

中文普通话，年轻、清晰、稍快但不赶。像独立开发者介绍自己刚上线的产品，句子之间留出一点呼吸，不使用叫卖腔。

## Final narration

我每天都在 X 和各类 Showcase 里，刷到很惊艳的 AI 产品和 UI 动效。

收藏越来越多，真正做进项目的，却很少。

因为很多 Demo 只有一段视频：没有源码，没有 Prompt，也没有接入说明。

所以我做了 AI Demo Vault。

这里把优秀产品拆成可以直接复用的 Build Blocks。

先在线预览，再看每个模块的源码状态、Prompt、README、License 和 Integration Guide。

搜索 Glass、Hero、Chat 或 Animation，找到你现在需要的那一块。

每个模块都从真实产品和真实交互出发，重新实现，清楚标注完成状态。

做 AI 产品时，你可以从一个可靠的模块开始，不必每次面对一张空白页面。

我会持续从 X、GitHub、Product Hunt 和 Showcase 中寻找值得复刻的灵感。

每天发现，持续拆解，逐步更新。

AI Demo Vault 已上线。

把你想让我拆解的 Demo 发给我，也欢迎关注后续的 Build Blocks。
